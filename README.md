# ManulCoffee Showcase

Create a modern, premium, minimalist frontend website for a fictional specialty coffee shop brand called “ManulCoffee”.

The goal is to make the website look like a real high-end coffee business in Riga, Latvia — elegant, warm, modern, visually strong, and suitable for a real small business portfolio project.

IMPORTANT:

- Frontend only for now.

- Do not add backend, authentication, database, admin panel, payments, or booking functionality.

- Use clean, reusable React components.

- Keep the code easy to maintain and suitable for later GitHub export and deployment.

- The site must be fully responsive and work well on desktop, tablet, and mobile.

DESIGN DIRECTION

Style:

- Modern

- Minimalist

- Premium

- Warm specialty-coffee atmosphere

- Clean editorial layout

- Strong visual hierarchy

- Spacious sections

- Avoid clutter

Main colors:

- Dark brown

- Light beige

- White

Suggested visual palette:

- Deep coffee brown for navigation, footer, dark sections

- Warm cream / beige for backgrounds

- White for important text and contrast

- Very subtle secondary neutral tones if needed

Typography:

- Large, elegant, bold headings

- Clean readable body text

- Modern premium typography

- Strong contrast between headings and body copy

- Avoid overly playful fonts

Use high-quality coffee-shop imagery as placeholders:

- Espresso

- Cappuccino

- Latte

- Iced coffee

- Pastries

- Breakfast

- Coffee beans

- Interior photography

- Barista preparation

- Exterior cafe photography

The overall aesthetic should feel sophisticated, warm, and contemporary rather than corporate.

--------------------------------------------------

1. GLOBAL HEADER / NAVIGATION

--------------------------------------------------

Create a clean sticky navigation bar.

Layout:

- Company logo on the far left

- Brand name “ManulCoffee” displayed prominently in large white letters

- Main navigation links placed compactly next to each other:

  - Menu

  - Locations

  - Reviews

  - Contacts

Navigation text:

- White

- Smaller than the main brand name

- Clean spacing

- Elegant hover effect

Behavior:

- Clicking the ManulCoffee logo/name returns to the homepage / top of the page

- Clicking each navigation link smoothly scrolls or navigates to the corresponding section

- Sticky header remains visible while scrolling

- Add a subtle background change or blur when the user scrolls

Mobile:

- Replace desktop navigation with a clean hamburger menu

- Menu should open smoothly

- Large touch-friendly navigation items

--------------------------------------------------

2. HERO SECTION

--------------------------------------------------

Create a visually strong full-width hero section.

Use:

- Large atmospheric coffee-shop image or subtle video-style visual

- Dark overlay for readability

Content:

- Large “ManulCoffee” heading in white

- Short premium brand slogan, for example:

  “Coffee worth slowing down for.”

Add two CTA buttons:

- View Menu

- Find a Location

Buttons should:

- Have elegant hover animations

- Match the brown / beige / white design system

- Scroll to Menu and Locations respectively

Hero should feel cinematic but minimalist.

--------------------------------------------------

--------------------------------------------------

Add a small homepage section titled:

Each card should include:

- Product name

- Short description

- Price in EUR

- Optional label such as:

  - Popular

For each location include:

- Address

- Opening hours

Mobile layout:

- Stack location information vertically

- Keep maps responsive

--------------------------------------------------

Create a visually attractive Reviews section.

Include:

- Google-style customer review cards

- Star rating

- Customer name

- Short realistic review text

- Optional customer avatar

IMPORTANT:

Use realistic demo / placeholder reviews styled like Google reviews.

“Loved by creators”

or

“Community Favorites”

Show lifestyle-style cards with fictional creators / local personalities:

- Photo holding a coffee near the cafe

- Name

- Short quote

Do not use real celebrities without permission.

Use fictional creator names and placeholder imagery.

Interaction:

- Horizontal carousel

- Right arrow to see more

- Left arrow to go back

- Smooth transitions

- Works with touch/swipe on mobile

Add a short elegant brand story section.

Include a short paragraph describing ManulCoffee as:

- Inspired by slow mornings and good conversations

Keep this section concise.

- Instagram

--------------------------------------------------

10. ANIMATIONS & INTERACTIONS

--------------------------------------------------

Use subtle premium animations only.

Examples:

- Fade-up on scroll

- Smooth section reveal

- Small image zoom on hover

- Button hover transition

- Smooth carousel movement

- Smooth menu filtering

- Header background transition when scrolling

Avoid:

- Excessive movement

- Flashy effects

- Heavy parallax

- Distracting animations

The website should remain fast and refined.

--------------------------------------------------

11. MOBILE-FIRST REQUIREMENTS

--------------------------------------------------

The website must be fully responsive.

Mobile behavior:

- Hamburger navigation

- Large touch targets

- Product cards stack cleanly

- Menu filters remain easy to use

- Reviews carousel works with swipe

- Maps remain responsive

- Buttons remain easy to tap

- No horizontal overflow

- Typography scales correctly

Design mobile carefully rather than simply shrinking desktop layout.

--------------------------------------------------

12. ACCESSIBILITY & UX

--------------------------------------------------

Use:

- Semantic HTML

- Good text contrast

- Alt text for images

- Accessible buttons

- Keyboard-friendly navigation where possible

- Clear focus states

- Proper heading hierarchy

Do not place important text over unreadable imagery.

Prepare the frontend with basic SEO best practices.

Include:

- Meta description

- Semantic headings

- Open Graph placeholders

- Descriptive image alt text

Suggested title:

ManulCoffee — Specialty Coffee in Riga

Suggested description:

ManulCoffee is a modern specialty coffee shop in Riga serving carefully crafted coffee, fresh pastries, and relaxed city atmosphere.

--------------------------------------------------

14. TECHNICAL REQUIREMENTS

--------------------------------------------------

Use a clean modern frontend stack.

Preferred:

- React

- TypeScript

- Vite

- Modern CSS or Tailwind CSS if appropriate

Use:

- Reusable components

- Clean folder structure

- Maintainable code

- Local static data for menu items, reviews, and locations

- No backend

- No database

- No authentication

- No payments

Make the project easy to export to GitHub and deploy later.

--------------------------------------------------

--------------------------------------------------

Use realistic placeholder content for:

- Menu items

- Prices

- Reviews

- Addresses

- Phone number

- Email

- Social links

- Creator names

Keep this demo content clearly fictional and easy to replace later.

Structure the data so that products, locations, and reviews can easily be edited in one place.

--------------------------------------------------

FINAL GOAL

The final website should look like a real, modern specialty coffee shop website that could realistically be presented to a small business client.

It should feel:

- Premium

- Warm

- Minimal

- Modern

- Trustworthy

- Easy to navigate

- Mobile-friendly

- Portfolio-ready

Prioritize strong visual design, clean UX, maintainable frontend code, responsive behavior, and realistic business presentation. 

IMPORTANT FOR ASSETS: For the initial version, use high-quality placeholder images appropriate for a premium specialty coffee shop. Keep images and content structured so they can be easily replaced later with the final brand logo, cafe photography, product photography, menu information, addresses, and contact details without redesigning the website.
