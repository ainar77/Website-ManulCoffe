# ManulCoffee frontend

## What I’ll build
- A responsive one-page specialty coffee website with a sticky desktop and mobile navigation.
- A cinematic homepage image, seasonal favorites, filterable menu, two Riga locations, review and creator carousels, brand story, contacts, and compact footer.
- Realistic but clearly fictional demo content, including prices, addresses, opening hours, reviews, and social links.
- Frontend-only interactions: smooth scrolling, menu filtering, mobile menu, swipe-friendly carousels, and local open/closed indicators.

## Visual direction
- Warm editorial design using deep coffee brown, cream, white, and restrained neutral accents.
- Elegant display typography paired with a clean sans-serif body face.
- Spacious layouts, sharp hierarchy, subtle motion, restrained image zoom, and accessible contrast.
- A cohesive set of generated café, drink, pastry, breakfast, and creator-style images, stored locally for easy replacement.

## Technical details
- Keep content in typed local data modules and split the page into reusable React sections and shared UI pieces.
- Use the existing TanStack Start, React, TypeScript, and Tailwind v4 setup without adding backend services.
- Add route-specific SEO metadata, social metadata placeholders without fake image URLs, semantic HTML, keyboard focus states, reduced-motion support, and descriptive image text.
- Verify the finished page at desktop and mobile sizes, including navigation, filtering, carousel controls, layout overflow, and current build diagnostics.
